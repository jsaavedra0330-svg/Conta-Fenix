Comprobantes de pago

  • Factura: comprobante que se emite generalmente a empresas o personas con RUC y permite sustentar costo, gasto o crédito fiscal cuando corresponde.
  • Boleta de venta: comprobante que se entrega normalmente al consumidor final.
  • Ticket: comprobante emitido por máquinas registradoras autorizadas.
  • Nota de crédito: sirve para anular, descontar o corregir una operación ya realizada.
  • Nota de débito: sirve para aumentar el importe de una operación ya facturada.

Excel básico

Excel permite organizar datos, realizar cálculos y crear tablas.

  • =SUMA(A1:A5): suma los valores.
  • =PROMEDIO(A1:A5): calcula el promedio.
  • =MAX(A1:A5): muestra el valor mayor.
  • =MIN(A1:A5): muestra el valor menor.

PowerPoint

PowerPoint sirve para crear presentaciones con diapositivas, texto, imágenes, gráficos y videos.

  1. Abre PowerPoint y elige una presentación.
  2. Agrega un título y escribe tus ideas principales.
  3. Inserta imágenes o gráficos relacionados con el tema.
  4. Usa un diseño sencillo y revisa la ortografía.
